** Función auxiliar =CuestionesJuntas=

Este bloque de código define la función =CuestionesJuntas(l)=, cuyo objetivo principal es *consolidar y "aplanar" objetos de la clase llamada =Cuestion=* dentro de una lista, manteniendo otros tipos de datos (como cadenas) intactos.

En detalle:
1. *=CreaLista(t)=*: Una función auxiliar que asegura que cualquier elemento sea tratado como una lista (si no lo es, lo envuelve en una).
2. *Iteración*: Recorre cada elemento =e= de la lista de entrada =l=.
3. *Strings y No-Cuestiones*: Si el elemento es una cadena o si su contenido (tras pasarlo por =CreaLista=) no es de tipo =Cuestion=, lo añade directamente a la lista resultante =p=.
4. *Aplanamiento de =Cuestion=*: Si el elemento es una instancia de =Cuestion= o una lista que contiene una =Cuestion=, utiliza =extend= para añadir los elementos individualmente.

*En resumen:* Transforma una lista mixta en una lista donde los objetos =Cuestion= (estén solos o en sublistas) se integran al nivel principal, mientras preserva la estructura de otros tipos de datos.

*Objetivo:* Esto permite que la clase [[Clase =ProblemaTipoProfe=][=ProblemaTipoProfe=]] muestre todas las cuestiones posibles para cada enunciado en lugar de una sola.
#+NAME: Metodo auxiliar para juntar cuestiones en formato para profe
#+begin_src python :noweb yes
def CuestionesJuntas(l):
    def CreaLista(t):
        return t if isinstance(t, list) else [t]
    p = []
    for e in l:
        if isinstance(e,str):
            p.append(e)
        elif not isinstance(CreaLista(e)[0],Cuestion):
            p.append(e)
        else:
            p.extend(CreaLista(e))
    return p
#+end_src

**** Función auxiliar =Siguiente (x, y)=

- =x=: lista de números naturales =[m_1...m_r]= tales   que =m_i < n_i= (es la lista de la que queremos calcular la siguiente).
- =y=: lista de números naturales =[n_1...n_r]= mayores que cero (lista de topes).
Devuelve =[k_1...k_r]= la siguiente lista a =[m_1...m_r]= (según el orden lexicográfico) tal que =k_i<n_i=.
En caso de no existir tal lista devuelve =[]=.
#+NAME: Definición de la función local Siguiente
#+begin_src python :noweb yes
def Siguiente(x,y):
    if x == [] :
        return []
    s = Siguiente(x[1:],y[1:])
    if s == []:
        if x[0]+1 == y[0]:
            return []
        else:
            return [x[0]+1] + [0 for i in x[1:]]
    else:
        return [x[0]] + s
#+end_src

*** Clase =ProblemaTipo=

Clase =ProblemaTipo (supuestos_y_cuestiones)=
- =supuestos_y_cuestiones= :: es una lista de listas de strings, =Supuesto=-s, o =Cuestion=-es.
Cada lista representa un conjunto de opciones excluyentes.
Para mayor comodidad, en el caso de que una de esas listas consista en un único objeto (una única opción), también se permite escribir directamente el objeto sin encerrarlo en una lista, es decir, la lista =supuestos_y_cuestiones= también admite objetos de tipo: string, =Supuesto= o =Cuestion=.

**** Implementación

La clase =ProblemaTipo= es un iterador que genera todas las versiones aceptables de un problema.
Cada variante resulta de tomar una de las opciones de cada una de las listas en =supuestos_y_cuestiones=, pero si la =precond=-ición de alguna de las opciones elegidas es =False= la correspondiente variante del problema es rechazada.
- El atributo =self.e= contiene la lista =supuestos_y_cuestiones=.
  Cada elemento de =supuestos_y_cuestiones= es a su vez una lista de opciones (excluyentes) correspondiente a cada componente (cada parte) del texto del problema.
 La combinación de distintas opciones crea el texto completo de una variante del problema.
El método =__iter__= inicializa el iterador.
El método =__next__= obtiene la siguiente variante del problema, pero asegurándose de que las precondiciones son satisfechas (si no la variante es desechada).
#+NAME: Definición de la clase ProblemaTipo
#+begin_src python :noweb yes
class ProblemaTipo:
    def __init__(self, supuestos_y_cuestiones):

El atributo =self.l= es la lista =self.e= normalizada para que todos sus objetos sean listas; =self.long= es el número de componentes que constituyen el texto de cada variante.
=self.i= es el iterador y =self.c= un contador.
#+NAME: Método __iter__ para la clase ProblemaTipo
#+begin_src python :noweb yes
def __iter__(self):
    self.l    = [x if isinstance(x,list) else [x] for x in self.e]
    self.long = len(self.l)
    self.i    = iter(Marcador([len(x) for x in self.l]))
    self.c    = 0
    return self
#+end_src

La generación de =variantes= de un =ProblemaTipo= se produce dentro de un bucle que solo se detiene cuando el intento (=try=) de iterar una vez más, =next(self.i)= falla por haberse agotado todas las variantes.

=self.long= guarda el número de elementos (es decir, de cadenas, =Supuesto=-s y =Cuestion=-es) que constituyen el texto del problema.

En cada iteración 1) =enunciado=, =hipotesis= y =cuestiones= comienzan estando vacías; y 2) se recorren uno a uno los componentes de la variante que se intenta construir.

Una vez se han recorrido todos los componentes se devuelve la lista:
=(str(self.c), enunciado, cuestiones)= que constituye la variante concreta del problema que se ha generado en esa iteración.
Cada tipo de =componente= es tratado de una forma distinta.

** Clase =ProblemaVF=

Para crear cuestiones del tipo =Verdadero/Falso=.

#+NAME: Definición de la clase ProblemaVF
#+begin_src python :noweb yes
from random import sample
class ProblemaVF():
    def __init__(self, enunciado, cuestiones, NumPreguntas):
        self.e = enunciado
        self.c = cuestiones
        self.NumPreguntas = NumPreguntas

    def __iter__(self):
        self.contador = 0
        return self

    def __next__(self):
        cuestiones = sample(self.c, self.NumPreguntas)
        self.contador  += 1
        return (str(self.contador), self.e, cuestiones)

#+end_src
